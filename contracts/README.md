# Rentra contracts

Foundry project for MockIDR, RentalItem (ERC-721 + ERC-4907), Reputation, and RentalEscrow.

```bash
forge build
forge test
```

Deploy to Base Sepolia from the repository root instructions in `../README.md`. The script is `script/Deploy.s.sol`. RPC URL and `PRIVATE_KEY` come from the environment (see `.env.example`). Do not commit a real key.
